## 1. The ₹2L GO book — *the instrument measured the wrong thing*

`data/paper/book.json` · **2026-06-12 → 2026-08-26 · 53 marks**

| | |
|---|---|
| Return vs ₹200,000 starting capital | **−0.68%** |
| Nifty 50 TRI, same window | **+3.42%** |
| Gap | **−4.10pp** |
| Worst in-window Nifty pullback | **−2.24%** (criterion 2 needs ≤ −10%) |
| Track length | 53 of 63 trading days |

**Verdict: void — not because it failed, but because it was never testing the system in use.** This
book ran the *validated funnel* — shrink-weighted, annual, tax-aware rebalancing. The user's real
money runs the deploy-into-weakness advisor, which shares no selection code and no names with it.
Every criterion could have gone green without saying anything about the money at risk.

The −4.10pp gap is **not evidence the strategy is bad**: 53 calm days cannot distinguish a good
strategy from a bad one, and the volatility gate never came within 8 points of firing. It is evidence
that the forward record was thin and pointed slightly the wrong way — which is exactly what the
pre-flight audit told the user before he invested, and he invested anyway, informed.

## 3. The research hedge forward run — *the instrument ran; the market gave it nothing*

**Hedge episodes: zero. `hedged == unhedged` on every row, to nine decimals.** The stress gauge never

**⚠️ And the cron died on 2026-07-21 — 38 days before anyone noticed**, while the rest of that repo

that is not running look identical on the chart.** That is the same failure shape as the seven label

**Requirement carried into the rebuild (Phase 1):** the hedge study must state
**"gauge fired 0 times in N days, last mark <date>"** on its face. Two overlapping lines are not a
status.
